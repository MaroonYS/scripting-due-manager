# 到期管家 for Scripting

紧凑原生风格的 iPhone 到期事项组件，支持账单、订阅、周期事项与 Apple 提醒事项。当前版本 **3.7.0**：减轻排序、分组与图标查找开销，加强并发保存、列表读取和页面退出保护；保留 216 个图标、统一尺寸、完整备注和独立完成按钮。「立即更新」仍在「查看提醒事项备注」下方。

## v3.7.0 · 架构、速度与稳定性

- 日期排序提取为不依赖存储、提醒系统或图标库的纯模块，每项预计算紧急度与行动日期；主列表直接使用轻量日期投影分组，不构造包含图标、金额和备注的展示对象。顺序、提前提醒、时区和同一期次语义保留。
- 主列表每次渲染共用来源隔离的图标索引，不再逐行扫描全部偏好；分组与状态文字使用同一时间。刷新计时只读启用事项的日期字段，不解析图标。旧重复 ID 的分配改为单调查找，保留预留原 ID、first-fit 顺序和全部事项。
- 本机 2,000 项合成基准，排序中位数 56.550→9.659 ms、主列表分组 99.455→10.042 ms；2,000 条偏好逐行查找 5.256→0.075 ms，包含新索引构建。新旧输出逐项一致；这些不是 iPhone、实际启动或 WidgetKit 延迟测量。
- 普通修改在保存前和备份后检查已观察到的外部更新，包括相同时间戳的内容变化；冲突明确提示并拒绝覆盖，重要快照和已完成操作不自动重放。共享存储仍没有原子事务，不能消除最后读取到写入之间的跨进程窗口。新增安全检查有少量提交成本，不把所有写入说成更快。
- 已存提醒列表筛选损坏时停止读取与写入，不把错误范围悄悄扩大为「全部列表」；旧版缺失字段、合法空数组、去重及前后空白兼容。原数据保留，可到恢复页检查或导出。
- 列表选择页独立成模块，读取防重与 10 秒只读期限、退出后忽略迟到结果；已接受的保存不取消、不重试，离页不再误关其他页面。前台更新尚未执行就进入后台时跳过；退出后的旧刷新回调不再读数据。

## 事项图标尺寸

- 选图网格、预览、图标库、编辑行、主列表与小组件共用原生图标渲染。使用 `resizable` 和官方 `scaleToFit` 等比适配完整绘制框，再居中放入独立布局框；不再仅靠字号或单轴宽度控制，不拉伸、裁切符号。
- 按场景保留不同层级：预览较大、网格居中、列表紧凑；主列表的可完成与隐藏事项使用同一图形尺寸。小组件保留原点击区域、来源／期次 Intent 和原生完成语义标题，只替换可见图形的缩放方式。
- 216 个图标定义、手选、颜色、日期、周期、完整备注、完成、通知、缓存保护和固定更新地址不变。形状比例仍保留，不承诺所有符号具有相同实心面积；真实 iPhone 排版、VoiceOver 与桌面着色模式仍需设备验收。

## 图标库 · 旅行、酒店、证件与联名卡场景

- 在原有 200 个选择之后追加 16 个原生符号：酒店住宿、酒店大楼、房卡门钥、行李托运、出发登机、抵达接机、航空里程、景点观光、机舱座位、酒店餐饮、证件挂卡、身份核验、会员证卡、铁路通勤、欧洲旅行和美洲旅行，共 216 个。原有名称、顺序、分组、颜色和手选保留；既有亚太地球符号只复用旅行搜索别名，不重复增加或更改原定义。
- 搜索覆盖订房、入住／退房、免费房晚、酒店餐饮与会籍、登机、接机、里程、行李、机舱、机场休息室、铁路通票、租车、轮渡、旅行保险、护照签证、居留、证件和会员卡，以及酒店卡、航空卡、旅行卡、铁路卡、返现卡与奖励卡。支持简繁中文、英文、常见酒店／航空品牌与计划别名，多词仍逐词匹配，全程本机查找。
- 信用卡场景提供酒店、航空、旅行、铁路、返现及奖励的关联推荐，保留自动图标和当前手选，总计最多 8 项。明确的信用卡语义，或「信用卡」事项类型与相关品牌，才参与联名卡分类；自动图标仍表示信用卡，不把普通酒店预订、航空会籍、礼品卡、SIM 卡、交通卡或护照误当信用卡。仅用于浏览的品牌词不会普遍成为标题／备注／列表推断规则，手选始终优先，点选草稿不会重排推荐。
- 推荐和逐项覆盖改用索引，自动／手动筛选避免不必要的图标解析；事项搜索文本由当前页面按需建立一次。新增优化不全局或持久化缓存用户标题／备注。退出保存页后，迟到的保存结果不再修改已退出页面、弹出提示或关闭其他页面；已接受的写入仍按原流程完成，不自动重放。
- 「立即更新」仍紧接「查看提醒事项备注」之后。250 毫秒保存延时、4／10 秒读取预算、30／5 分钟刷新请求及前台同步保留；不通过缩短保护间隔承诺系统即时刷新。
- 新增名称经 Apple 本机 CoreGlyphs 官方可用性目录核对，首次支持 iOS 13–16.1，兼容项目要求的 iOS 17。不引入外部 Logo、图片或联网图库，不分发 Apple 目录或图形资源。符号仅表示用途，不表示余额、收益、权益资格或风险，不访问银行账户或提供金融建议；日期、周期、完整备注、完成、通知、缓存保护、备份及固定更新地址不变。

## 现有操作与稳定性

- 两个图标入口共用选图页：点击图标先更新大图预览，右上角确认后应用；取消或返回不应用草稿。默认展示 8 个推荐符号，包含自动匹配、当前选择及关联场景；用菜单浏览一个分类，或搜索全部 216 个符号，不再逐个展开长主题列表。支持简体、繁体、英文及 SF Symbol 名称搜索，全部在本机完成。
- 主界面「设置与管理 → 事项图标」统一管理手动事项和 Apple 提醒事项。可搜索事项、筛选来源及自动／手动方式，并选择是否包含已完成或隐藏的手动事项。列表明确显示图标方式、名称、原有颜色及不可用的旧选择；提醒读取异常可在此重试。
- 集中入口确认「保存图标」只改该项外观，不必进入完整事项编辑；不修改日期、周期或备注，也不改写 Apple 提醒事项。编辑事项时确认「使用此图标」只更新表单，仍需保存事项。两处的自动匹配都清除该项手选覆盖，包括旧手动图标；其他事项保持不变，保存冲突或失败不会冒充成功。
- 金额开关、三个尺寸预览及上次组件操作移入「组件与显示」。主界面保留提醒集成、通知、数据安全和「刷新桌面组件」入口；刷新仍先重读数据。批量图标覆盖采用来源＋ID 索引，搜索文本只预计算一次，主列表用单次分组及同一时刻计算状态。仅改图标只请求组件刷新，不再等待无关的通知维护。
- 提醒读取有截止时间，组件总读取预算为 4 秒，主界面为 10 秒；超时走原有缓存或明确提示，迟到结果不写缓存。多组件同时同步时，共享请求标记保护已保存的新结果；动画或状态提示读取失败不再隐藏有效事项。
- 常规提醒同步请求 30 分钟后更新，读取失败或缓存回退时请求 5 分钟后重试；已知到期时刻和午夜按真实边界请求。返回前台或点「刷新桌面组件」时，先重读最新数据和同步提醒。完成操作及时请求刷新，可选通知维护不再阻塞下一次完成。
- 点击小组件左上角主题、提醒事项标题／日期或对应预告，先显示该项的完整备注页：保留换行和全文，不自动跳出。页面显示标题、所属列表及已完成状态，可重新读取，再明确选择「在提醒事项中打开」。主界面「系统提醒事项 → 查看提醒事项备注」提供按标题／列表查找的备用入口。
- 空备注、无效／已删除事项、权限不足、读取超时及系统详情打不开均明确提示。备注在页面打开后实时读取，不写入缓存、URL 或备份，不会被用作跳转地址。旧 3.4.0 组件链接同样进入备注页；完成按钮保持独立。
- 仅保留系统图标，移除此前新增的内置 Icons8、在线图库、GitHub／金融品牌图库、登录与搜索模块，以及 829 组 PNG／离线 JSON 素材。不恢复更早已移除的混合品牌 Logo 库。
- 标题、备注在本机分别匹配：明确具体的标题优先；高置信度备注可细化泛化标题，普通备注在泛化标题之后、列表分类之前参与匹配。Wallet Plan 的明确编号模块优先。手选符号始终优先；缓存仅保存图标提示和置信度，不保存 Apple 提醒事项备注正文。
- 桌面小组件的完成按钮把完整点击区域放进实际标签；中、大号行按事项来源、ID 和当前期次标识保持独立身份。完成继续核对真实事项和期次，禁止缓存／只读操作，过期或已不存在的事项明确提示。
- 备注页不依赖 Apple 私有跳转链接；只有「在提醒事项中打开」按钮仍尝试系统详情链接，并在打开前重新查验 ID。不能直接跳转的账户仍可读取备注。小组件到宿主的原生传参和系统详情定位需当前 iOS 真机验证。
- 升级后运行一次主脚本，会清理本脚本旧图库订阅、相关选图记录和两个本机钥匙串凭据。原先保存的 SF Symbols、事项、周期、日期、通知及完成记录保留；旧外部选图恢复为系统符号。旧 JSON 备份仍可导入，已移除的图库不会被恢复。

完整变化见 [发行说明](./RELEASE_NOTES.md)，本次架构、性能与安全验证见 [3.7.0 QA](./docs/QA-v3.7.0.md)，图标尺寸与旅行兼容性见 [3.6.1 QA](./docs/QA-v3.6.1.md)、[3.6.0 QA](./docs/QA-v3.6.0.md)。刷新间隔是脚本发出的请求，实际执行由 iOS 决定。旧版本说明以各 Git 标签和发行页为准，不代表当前功能。

## 日常使用与安全

- 手动事项提供 11 种类型，支持一次性或每 1–99 天／周／月／年重复，并保留月末及闰日锚点。完成一次只推进一期，不跳过累计逾期。
- 「重复」卡片可设置提前 0–365 天。从提前日零点进入待处理，不改变真实到期日。仅设置提前天数不会产生通知；请另行开启「通知与提醒」。
- 小号展示最紧急的 1 项，中号显示 2–3 项，大号按实际高度显示 3–5 项。左侧图标只完成本期，文字打开详情；完成不会执行付款、续订或操作银行账户。
- Apple 提醒事项可筛选一个或多个列表。读取失败时只使用 24 小时内且筛选范围相同的缓存，明确标记并禁止从缓存完成。
- 旧编辑页保存／删除有冲突校验；重要写入前建立本机快照，支持 JSON 备份及恢复。状态不能识别时拒绝覆盖，不重置事项。
- 组件使用简体中文、繁体中文或英文，日期按系统地区格式；实际刷新、完成后的界面变化和通知送达受 iOS／WidgetKit 调度影响，不承诺实时动画或永久后台运行。
- 图标匹配不联网，不上传标题、备注、金额或日期。共享 Storage 不是密码保险箱，请勿保存完整卡号、密码等秘密；组件内容可能在锁屏可见。

## 一键安装或更新

[在 iPhone 上安装或更新到期管家](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fgithub.com%2FMaroonYS%2Fscripting-due-manager%2Freleases%2Flatest%2Fdownload%2Fdue-manager.scripting%22%5D)

请更新手机里原有的「到期管家」，不要先删除脚本或重建事项。更新后运行一次主脚本，完成旧图库设置清理和提醒事项实时同步，再请求刷新用户小组件。首次安装才需要添加 Scripting 桌面组件并选择本脚本。

固定链接与 remoteResource 更新地址保持不变。主脚本底部「检查并更新版本」会显示版本及说明，安装前保存快照；正式发行附带校验文件和签名来源证明。详细要求与操作见 [使用说明](./到期管家/README.md)。
