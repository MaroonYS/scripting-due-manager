# 到期管家 for Scripting

紧凑原生风格的 iPhone 到期事项组件，按 Apple 公布的 WidgetKit 尺寸自适应小、中、大版式，支持信用卡账单、订阅、周期事项与 Apple 提醒事项。2.4.0 将周期间隔改为可输入的 1–99 正整数，并允许每个手动事项设置 0–365 天的提前提醒。2.4.2 将提前设置并入同一个「重复」卡片，并用原生 `LabeledContent` 让数字行左侧始终明确显示「间隔」与「提前提醒」；间隔值右侧仍会根据周期动态显示天、周、个月或年。提前天数生成“行动日”，用于排序、主脚本的「需要处理」分区和组件刷新；真实到期日仍是周期推进锚点及组件显示日期，0 表示不提前。本功能只调整应用内处理时机，不会创建系统推送通知。

现有组件排版保持不变：小号金额与备注继续左对齐；中、大号的金额和备注继续使用固定 116/124 pt 右栏与单行槽位，过长时先使用系统字距收紧，最低保持 85% 字号，再从中间省略以同时保留首尾信息。该策略不会改变标题宽度、组件容量、行高或完成图标点击区。所有组件文案会读取 iPhone 首选系统语言，在简体中文、繁体中文和英文之间自动切换，其他语言使用英文兜底；日期始终按完整的系统语言与地区格式显示。小号左上角仅保留当前图标的本地化语义名称，不再重复显示图标；当前事项图标仍是 17 pt 完成按钮，点击热区保持 40 pt，主体标题继续按实际宽度使用 16/15/14 pt 适配一、二、三行。小、中、大组件不显示“明天”“2 天后”“逾期 6 天”或 24 小时实时倒计时，只显示明确的本地化日期；小号底部预告同步显示下一事项日期。中号保持 17 pt 图标、38 pt 点击热区、2–3 项动态容量及无分隔线布局；大号保持 18 pt 行图标、40 pt 点击热区、26 pt 摘要图标，并按实际高度显示 3–5 项。中、大号标题最多两行，点文字打开详情；只读或缓存事项的图标会变灰，右侧保留绝对日期及锁定或缓存标识。大号继续使用系统「提醒事项」风格的摘要、分区和留白节奏，完成后由后续事项补位。交互后的内容更新时间仍由 WidgetKit 决定，不声称使用 Apple 私有的点击瞬时动画。Apple 提醒事项可按一个或多个具体列表筛选；图标按“事项标题 → 精确 List 分类 → List 产品短语 → 备注 → 默认值”离线推断，覆盖 126 个 List 图标方向与 1,100+ 个简体、繁体和英文别名；备注正文不会写入缓存。手动事项提供 11 种到期类型，并内置 130 个本机 SF Symbols。

## 一键安装或更新

[在 iPhone 上安装或更新到期管家](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fgithub.com%2FMaroonYS%2Fscripting-due-manager%2Freleases%2Flatest%2Fdownload%2Fdue-manager.scripting%22%5D)

固定链接始终指向 GitHub 最新发行版中的不可变安装包，避免分支原始文件的 CDN 缓存返回旧版。安装后，脚本还会通过 `remoteResource` 使用同一地址检查更新；主脚本底部的「检查并更新版本」入口会在每次运行时生成新的下载请求，减少 Scripting 复用旧资源的可能。

从 1.2.0 升级时先不要删除手机里的旧脚本；让现有脚本更新到最新版后运行一次，它会把旧事项迁移到本机持久域。2.4.0 可兼容读取 schema v1/v2 数据，旧事项的提前天数默认为 0，并在下次保存时写为 schema v3；无需重新添加事项或桌面组件。

完整功能说明和安装要求见 [`到期管家/README.md`](./到期管家/README.md)。

## 仓库内容

- `到期管家/`：可维护的 Scripting 源码。
- `到期管家.scripting`：可直接导入的发行包。
- `tests/`：日期、周期、图标匹配、提醒事项分层图标识别、组件布局、队列补位、幂等完成、列表筛选、只读权限和冲突保护测试。
