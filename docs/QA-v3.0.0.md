## 实现范围

- 829 枚离线图标、23 个分类：766 枚应用／品牌／产品等图标，63 枚财务、日期、家居与生活图标。包含变体，不代表同等数量的独立 App。全部为同一 Icons8 Windows 11 Color 风格，未用旧混合图库补缺。
- 保留 130 个 SF Symbols 与既有本机分类。手动事项和 Apple 提醒事项分别以 `source + itemID` 保存独立选择，没有全局图标模式或按标题自动替换彩色图的行为。
- 手动选图与事项保存／完成一起提交，取消不落盘，写入失败不关闭。图标比较初始值以拒绝覆盖其他页面的更新；未触碰的选图保留最新值。删除手动事项仅移除其对应的新图标记录，并在删除前快照中保留事项和图标。
- Apple 提醒事项选图只写到期管家的本地设置，不调用 EventKit 写入，不修改系统名称、备注、日期或完成状态。
- 主列表及小、中、大桌面组件、下一事项预告和大号摘要共用选择；锁屏附件仍使用系统符号。完成按钮保留原事项／周期参数和语义标签，文字详情入口分离。只读及缓存项不产生完成按钮。
- 彩色完成图标 24 pt；主列表、小号和大号热区 40 pt，中号保持 38 pt。小号预告图标 12 pt，大号摘要 30 pt。图案等比显示，不裁剪、抠背景或重绘；29 枚深色标志仅在深色模式加浅色底板。
- 主数据继续使用 schema v3。旧品牌字段只作为兼容元数据保留，不恢复旧图库；新字段可往返快照与 JSON 备份。合法但当前未收录的新图标 ID 保留，显示回退系统符号。

## 图片与运行时边界

每张 PNG 均为 96×96，逐项记录来源地址、原始标签、大小和 SHA-256，并附带同字节的独立 Base64 JSON。来源与权限说明见 [素材声明](../到期管家/assets/icons8/NOTICE.md)。项目发布者确认了本项目离线打包及公开分发授权；该确认不等于本次验证审阅了授权书，也不为下游授予独立素材再分发权。

图库每页最多加载 24 枚、四路并行；主列表行及设置预览出现后才读取图片，离屏时释放行内引用。共享成功缓存最多 64 项，在途请求最多 64 项，重复请求复用。单个 PNG 读取 650 ms 后尝试独立 JSON，整体可选加载期限 1,400 ms；组件只预读当前可见项目，外层期限 1,600 ms。未知 ID、损坏内容及超时均回退系统符号，不改变已保存选择，不阻断完成按钮。没有运行时图标服务网络请求，也没有将整库 Base64 编入 TS 模块。

PNG 及 JSON 使用原始字节；本机 QA 合成图仅用于检查比例、颜色和明暗对比，不写回源图。

## iPhone 真机仍需验收

本轮未在 iPhone 的 Scripting／WidgetKit 中实际运行，以下不是已通过项目：

1. 更新原脚本后，原事项、周期、通知设置和完成记录保留；不先删除旧脚本。
2. 为两条手动事项分别选择不同彩色图或 SF Symbol，确认取消不变、保存后逐项生效；提醒事项仅改变本地显示。
3. 小／中／大组件、主列表、下一事项预告、大号摘要的图片比例、留白和原色；浅色／深色及 iOS 着色模式逐一检查。
4. 彩色图标中心和热区边缘点击只完成对应事项，文字打开详情；快速连点、旧时间线、缓存／只读事项及完成后队列补位保持安全。
5. 图库快速翻页、搜索、进出页面、全库滚动、VoiceOver 语义标签及大字号布局。特别检查 Scripting 对图像标签和 LazyVGrid 的实际渲染。
6. 导入后的本地资源路径、PNG 解码与 JSON 备用；缺图时系统符号仍可见可点，后续重开页面可重试。
7. 组件刷新和通知送达依赖 iOS／WidgetKit 调度，本机测试不保证瞬时动画或准点横幅。

采用的原生视图接口参照 Scripting 的 [Image](https://scriptingapp.github.io/zh/guide/Views/Image/)、[LazyVGrid](https://scriptingapp.github.io/guide/Views/Layout/LazyVGrid/) 和 [Shapes](https://scriptingapp.github.io/zh/guide/Views/Shapes/) 文档；文档支持不等于真机排版验收。
