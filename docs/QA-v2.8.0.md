## 改动范围

用户确认「系统图标与品牌 Logo，各事项独立任选」。编辑页使用并列的两类选项，所选内容随事项原子保存；仅切换浏览类别或取消编辑不写设置。品牌选择保留原 SF Symbol，切回时可继续使用。选择系统自动匹配也明确保存为系统类型，不能再次由标题自动选中品牌。

设置入口改为「事项图标」，覆盖手动事项与 Apple 提醒事项；选择按来源和 ID 精确隔离。主界面及小号组件只读取该事项的明确品牌选择，旧全局样式不再影响显示或在保存品牌时被改动。中大号、锁屏和小号底部预告仍使用系统图标。Apple 提醒事项的系统选项沿用既有系统符号推断，具体 SF Symbol 手选目录仍只在手动事项编辑页提供。

已选品牌和显式系统选项保留。未指定品牌的事项，包括曾受全局品牌优先影响而自动显示品牌的旧事项，现使用系统图标；这是本版的新规则，不伪造迁移选择。旧全局字段与未知品牌 ID 继续无损往返备份，未知品牌显示系统后备。存储 schema 仍为 v3，不批量重写用户数据。

取消共享 `BrandLogo` 的圆形遮罩，使用 `logo.size` 的矩形内容边界。330 个生成 PNG 为 144 px 画布、120 px 完整内容区域，以 28.8 pt 图像居中放入 24 pt 边界，只去掉打包新增的每侧 12 px。SafePal 原图 20 pt、Telegram 原图 24 pt，不额外放大。保留图案背景和四角，不批量抠图或重绘；不同源图内部留白仍会造成视觉大小差异，不声称完成逐项光学归一化。

40 pt 完成热区、标签语义、事项与周期参数、缓存和只读保护、启动入口及异步加载机制保持。333 个 PNG、333 个离线 JSON、来源清单、原文件哈希、许可与 NOTICE 不改字节。

## 发布核验与 iPhone 待验收

发布流程重新打包并校验 ZIP、解压源码一致性、LICENSE／NOTICE 字节一致、素材哈希及固定更新 URL。官方工作流运行测试、严格检查及来源证明核验；发行后独立下载包核对 SHA-256、本地字节及指定 main 提交的官方工作流来源。

iPhone 更新后，无需删除脚本或重建事项：

1. 分别给两个手动事项选择系统符号和品牌 Logo，保存后确认主列表与小号组件一致；切换其中一项不影响另一项，改标题不改变已选品牌。
2. 仅浏览另一图标类别或取消编辑，确认原选择保留；选品牌再切回系统，确认原系统符号可继续使用。未指定品牌的 ChatGPT 等名称应显示系统符号。
3. 在「事项图标」为 Apple 提醒事项切换两类，确认只影响对应事项；缓存、只读及坏图继续安全回退。
4. 检查 Ultra Mobile 等方形图案四角、ChatGPT 外缘、SafePal／Telegram 原尺寸及深浅色、系统着色；点击左图标仍完成同一期，文字仍进详情，VoiceOver 标签正确。
5. 确认中大号、锁屏、底部预告仍使用系统图标，主界面轻量启动及图片读取失败回退保持正常。
