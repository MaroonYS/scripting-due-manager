## 实现与边界

用户明确仅移除旧品牌／App Logo 库，保留 SF Symbols。撤销此前未发布的透明／圆角混合方案，不替换为另一套未经确认的图库。

删除品牌浏览及设置界面、编辑器品牌分类、品牌匹配／渲染／加载模块、素材清单、333 个 PNG、对应离线 JSON 和专用素材工具。主界面、小组件及编辑页不再依赖品牌目录，也不访问品牌图片。旧素材与移除前工作已在本机临时备份保留，可恢复；历史发行与历史 QA 文档未删除。

保留手动事项独立 SF Symbol 选择及本机自动分类。旧品牌事项显示其原 SF Symbol；无手选符号时按标题／类型使用已有的本机系统图标规则。保留 40 pt 完成按钮、语义标签、事项／周期校验、快速重复操作防护和缓存只读保护。

存储 schema 不变。旧 smallWidgetIconStyle 与 itemBrandChoices 只由无图片依赖的 legacy_icon_preferences.ts 验证并保留，不决定显示；未知但格式合法的旧 ID 不会丢失。正常保存、完成、撤销、快照、备份导入／导出均不清空这些旧字段或事项数据。格式损坏的数据继续拒绝静默覆盖。
