# v2.5.0 验收与边界

## 自动验证

- `bun test tests`：日期/周期、图标、列表权限/缓存、存储、恢复、通知计划与去重、更新检查和 UI 接线回归。
- TypeScript 7.0.2：`tsc -p tsconfig.validation.json`。当前 UI 使用 Scripting 接口声明替身，不能据此断言原生渲染正确。
- 打包后解压并逐文件比较源码；发行后从固定 latest 链接反向下载核验版本和 SHA-256。
- 发布流水线重复执行测试、类型检查和包内容比对；已有版本的资源不能被不同内容覆盖。

## 必须在 iPhone 上验证（尚未执行）

使用临时测试事项，避免操作真实银行/订阅提醒。测试后删除临时事项即可。

1. 从旧版本更新，核验底部 `2.5.0`；旧事项、列表筛选和原有小组件继续可用。
2. 编辑按月／按年事项，检查“间隔”“提前提醒”和“开始处理”均显示；间隔 13/99 可保存，0/100 被拒；提前天数 0/365 可保存。
3. 小号：短标题、两行、三行中英混排；有／无金额备注；有／无具体时间；23:59 和英文 11:59 PM。确认标题、19 pt 辅助栏和底部预告不重叠。时间不得进入右上角或压缩标题。
4. 中号／大号：长标题、长卡号备注、具体时间、同日多项、跨年日期；检查既有行容量和边距。分别验证浅色、深色、系统着色、大字体和窄屏。
5. 打开 VoiceOver：完成图标应朗读“完成”及事项名，不应只朗读图标形状；点击文字和图标的行为仍分别为详情与完成。
6. 用一次性／月末／季度临时事项执行完成、连续快速点击、完成后撤销。应只推进一次；若完成后又编辑，旧记录撤销必须拒绝覆盖。
7. 导出 JSON → 新增测试事项 → 导入原备份，核对替换确认、自动快照和完整恢复。尝试非法 JSON／重复 ID／不存在的列表范围，原数据不得被清空或扩大读取范围。恢复后通知关闭。
8. 通知默认关闭不弹授权；主动开启，设 2–3 分钟后的测试通知。检查权限拒绝、重新允许、改名／改期／完成／删除／关闭／恢复，过期安排被取消、无重复。
9. Apple 提醒同步失败／列表删除：检查缓存说明、最后成功时间和重试入口；只读／缓存行不能完成。恢复网络后重新选择有效列表并更新。
10. 版本检查：正常／断网／没有新版本；检查更新说明和安装前快照。离线不能声称“已是最新”；不自动安装旧版本。

## 不能通过脚本保证的行为

- WidgetKit 实际刷新时间与 Reminders 私有动画效果。
- 系统通知横幅准时显示、长时间不运行仍无限期补充后续通知。
- 缺乏 EventKit 可靠修订标识时，安全自动撤销 Apple 周期提醒。
- 卸载 Scripting、设备丢失后的本机快照恢复；需用户另行保存导出的备份文件。
