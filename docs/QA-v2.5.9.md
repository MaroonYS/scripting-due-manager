## 新增的 8 项保护回归

1. 仓库与脚本目录的 LICENSE、NOTICE.md 字节一致，含正确维护者及许可标识。
2. 全部 TS、TSX、MJS 源码及测试包含声明头，防止正常维护中意外漏带。
3. 官方运行时与宿主 remoteResource 更新地址均保持原固定地址。
4. 完整许可链接绑定当前安装版本，拒绝异常版本路径。
5. 在无网络、无 Storage 能力的适配器中执行实际版权页，验证限制、例外和链接。
6. 版本信息异常时仍可离线显示限制，仅隐藏不能安全生成的版本化链接。
7. 主界面有版权入口，桌面组件不引入版权页面。
8. 发布流程只默认在官方 main 执行，要求声明一致、校验文件和指定来源验签后再发布。

这包含源码级检查和无界面执行，不等于 Scripting 原生组件、链接触摸或真机排版验证。

## 包与发布验收

打包后执行 ZIP 完整性检查，解包并逐文件核对源码（原约定排除 README.md、.DS_Store），
另核对随包 LICENSE、NOTICE.md 与仓库根目录一致。正式发布必须通过 GitHub
上的测试、包检查、签名来源生成和验签，成功后才发布安装包与 SHA256SUMS。
发布后应下载同一版本，检查哈希、与本地包比较，并使用完整提交 SHA 再验签。
操作方法见 [PROTECTION.md](./PROTECTION.md)。

初始回归发现旧测试固定了 v2.5.8 版本字面量，并依赖 URL 常量的源码拼写；
已更新到 v2.5.9，将 URL 断言改为实际导出值比较，保留原地址约束。
