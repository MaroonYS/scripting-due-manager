## 加载与失败路径

先调用 `UIImage.fromFile`；若导入后的资源路径不可用，则从同字节内嵌 PNG 调用 `UIImage.fromBase64String`。
两个接口的使用依据见 [Scripting UIImage 文档](https://scriptingapp.github.io/guide/Utilities/UIImage)。
只有深浅两份都解码成功才隐藏原 SF Symbol，单一文件的品牌复用一次解码结果。
明确区分 `not-bundled`、`decoder-unavailable` 和 `decode-failed`，给出未收录、更新宿主或重新安装的不同提示。
运行时不下载图片、不请求品牌网站或 App Store、不读取 SIM／联系人，也不上传事项。
目录每页最多解码 32 个图案，小号组件只解码当前主图案；不缓存整库 UIImage。
