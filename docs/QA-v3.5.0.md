日期：2026-10-01。用户报告两个图标入口逻辑混乱、选择困难，并要求优化整体脚本。

## 修改范围与数据边界

手动编辑与集中图标入口共用 `SystemIconPicker`，选择保留为草稿，点击只更新预览，明确确认后调用所属入口的提交操作。取消或返回不应用；重复确认受忙碌锁保护，失败保留选图页。编辑页确认只更改表单，仍需保存事项；集中入口只保存该项外观。

默认推荐网格显示 8 个本机符号，优先自动匹配、初始选择和相关类别。分类菜单一次浏览一个类别，搜索覆盖全部 182 个符号，并保留简体、繁体、英文、SF Symbol 名称、多词 AND 匹配及原有目录顺序。推荐初始项不随每次点选重排，当前选择在网格与大图预览中标明。

「事项图标」页提供来源、自动／手动方式和已隐藏手动事项筛选；默认仅列出启用的手动事项及原有范围内未完成、有到期日期的系统提醒。来源＋ID 保持独立，不以同名或相同 ID 跨来源覆盖。列表保留自动图标的颜色，正确区分旧手动设置与自动匹配；读取异常可重新读取。

手动事项集中改图核对原事项版本及初始图标选择，从最新数据更新图标，不重写过期表单。恢复自动同时清除该项旧 `iconName` 及本地覆盖；提醒事项只更新本地图标选择，不调用 EventKit 保存。保存成功后刷新异常只提示已保存，不要求再次保存。仅改图标只请求组件刷新，不执行通知维护。

主界面保持事项、提醒集成、通知、恢复、更新和刷新入口。金额开关、三个组件预览及操作诊断进入独立「组件与显示」页，使用现有状态和回调。图标搜索文本预计算一次，批量图标覆盖按来源＋ID 建 Map，主列表用一次分组和同一时刻计算状态；排序和到期规则不变。

保留 3.4.2 的组件 4 秒／主界面 10 秒读取预算、迟到结果与共享缓存保护、30／5 分钟及真实边界刷新请求、前台同步、授权／列表保存排队和监听清理。完整备注按准确 ID 实时读取，不保存正文到缓存、URL 或备份；完成按钮、历史、周期、通知与备份保护不变。Storage 无原子 compare-and-set，本次冲突校验不代表跨进程事务保证。

## 原生验收

本机环境没有可控制的用户 iPhone，未操作真实提醒。本机自动化不等同于以下项目已在设备通过：

1. 两个选图入口的大图预览、8 项推荐、自适应网格、长标签、分类菜单和键盘搜索，在小屏与较大字体下应可读、可点击。
2. 点击只预览，取消／返回不应用；确认后正确回到事项编辑或图标列表。编辑事项仍需保存，集中入口只改图标。
3. 来源、自动／手动、隐藏开关及搜索组合能定位正确事项；旧手动图标恢复自动后，主界面与组件使用同一自动结果。
4. 「组件与显示」中的金额开关、三种尺寸预览和操作诊断可达；首页刷新与系统提醒列表设置继续工作。
5. 更新原脚本并运行一次后，旧事项、周期、日期、通知、完成记录和备份保留；主题点击仍打开准确的完整备注，完成按钮仍独立。
6. 在提醒事项中修改后返回前台、临近到期、午夜、离线或权限撤销时，记录脚本同步结果与桌面实际更新；不按请求时间推定准点呈现。

所有刷新时间均为脚本请求，实际更新、完成后的画面变化及通知送达仍由 iOS／WidgetKit 调度。不承诺即时刷新、常驻运行或原生动画。
