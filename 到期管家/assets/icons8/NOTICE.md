## Included files and provenance

- 829 original 96×96 PNG files, each accompanied by one independent JSON fallback encoding the exact same PNG bytes. 766 entries are application, brand, product-series or related logos; 63 are finance, date, household and general illustrations. The count is not a count of distinct applications.
- [sources.json](./sources.json) identifies every source page, public website PNG URL, original label, category, dimensions, byte length and SHA-256. `lightBackplate` records only a view-layer dark-mode contrast plate; it is not a modification to the asset.
- Catalog sources: [Logos](https://icons8.com/icons/set/logos--style-fluency), [Finance](https://icons8.com/icons/set/finance--style-fluency), [Time and date](https://icons8.com/icons/set/time-and-date--style-fluency), [Household](https://icons8.com/icons/set/household--style-fluency), and the specifically selected [Earth Smiley](https://icons8.com/icon/9GC5rqCM5uDh/earth-smiley).
- Files were obtained on 2026-09-09 from normal public website PNG assets. The 96×96 Claude file from the website's Download workflow was byte-identical to its displayed 96×96 PNG URL. No Icons8 developer API, runtime download, account credentials, or paid-format access bypass is used by the application.
- Source images are not cropped, recolored, stretched, background-erased, redrawn, or re-encoded. The UI scales proportionally within its icon slot. Twenty-nine dark marks receive a light contrast plate on dark backgrounds only, behind the unmodified image.
- The old mixed-source brand library is not included. Historical packages retain their own notices and rights.
