# 到期管家

一款为 [Scripting](https://apps.apple.com/us/app/scripting/id6479691128) 编写的 iPhone 桌面组件，用来统一跟踪信用卡账单、订阅、周期账单、一次性截止日期和 Apple 提醒事项。

## 固定安装与更新链接

[在 iPhone 上安装或更新到期管家](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fgithub.com%2FMaroonYS%2Fscripting-due-manager%2Fraw%2Frefs%2Fheads%2Fmain%2F%E5%88%B0%E6%9C%9F%E7%AE%A1%E5%AE%B6.scripting%22%5D)

这个链接始终指向 `main` 分支的最新版安装包。脚本也配置了 Scripting 官方的远程资源更新地址，每小时允许检查一次新版本；实际检查和安装时机由 Scripting 决定。首次安装仍需在 iPhone 上确认。

## 已实现

- 原生 iOS 风格的分组列表、系统色和浅色/深色组件背景。
- 组件左侧提供类似「提醒事项」的完成圆圈；圆圈负责完成，文字区域负责打开详情，避免嵌套点击冲突。
- 小号组件显示最紧急的 1 件；中号按高度显示 2–3 件；大号按高度显示 5–7 件。
- 完成当前事项并刷新后，后续事项会自动补入空出的行；同一天有具体时间的事项按时间先后排列。
- 完成按钮带有本期识别码，重复点击或旧组件快照不会把周期事项误推进两期。
- 手动周期事项完成一次只推进一期；一次性事项完成后移入「已完成或隐藏」。
- Apple 提醒事项可直接从组件标记完成；系统周期提醒的下一次实例由 iOS 生成。
- 提醒事项读取失败时最多回退到 24 小时内的成功快照；缓存行会明确标记且不可从组件完成。
- 支持一次性、每 N 天、每 N 周、每 N 月和每 N 年，以及月末和闰日规则。
- 在 Scripting 内直接新增、编辑、删除和完成事项，无需修改代码。
- 手动事项数据保存在当前脚本的私有 `Storage` 中，不会被打进远程安装包。

## 安装要求

- iOS 17 或更高版本（交互式桌面组件要求）。
- Scripting 2.4.9 或更高版本（直接完成 Apple 提醒事项使用 `Reminder.get`）。

安装步骤：

1. 在 iPhone 上打开上方固定安装链接，确认导入「到期管家」。
2. 先运行一次主脚本，添加手动事项。
3. 如需合并 Apple 提醒事项，打开对应开关并完成授权。权限必须在可见的主脚本内授予，桌面组件无法弹出授权框。
4. 长按 iPhone 主屏幕，添加 Scripting 组件。
5. 长按新组件 →「编辑小组件」→ 选择「到期管家」。
6. 分别在真实主屏幕上检查你使用的小、中或大号版式。

以后更新时可继续使用同一个链接；启用远程资源后，Scripting 也会按自己的调度检查固定地址。无需保存不同版本的 `.scripting` 文件。

## 使用方式

- 点事项左侧空心圆圈可完成当前一期；点文字可打开事项详情。
- 对手动周期事项，组件完成一次只推进一个周期，不会静默跳过累计逾期记录。
- 对 Apple 提醒事项，组件会直接把系统提醒标记为完成；若它是重复提醒，下一次出现时间由 iOS 控制。
- 完成按钮只记录「本期已处理」。它不会自动付款、续订、取消订阅或操作银行账户。
- 设备锁定时，iOS 可能要求先解锁才能执行交互。
- 可在主脚本中预览三种尺寸，并手动请求刷新桌面组件。

## iOS 刷新限制

桌面组件不是常驻进程。脚本会在下一个本地午夜、最近的具体到期时刻、开启系统提醒事项后的约每 3 小时，或用户交互时请求新数据，但最终执行时间由 WidgetKit 决定，可能延后。

动态 `DateLabel` 能在脚本未运行时继续更新倒计时文字，但不会重新查询 Reminders。如需必须准时弹出的通知，应同时在 Apple 提醒事项或日历中设置通知。

手动事项的具体时间按设备本地时钟保存；跨时区旅行时会保持相同墙钟时间。系统提醒事项的具体时间则按其绝对时刻换算为设备当前时区。

`Storage` 是脚本私有存储，但并非密码保险箱。请勿填写完整卡号、密码等秘密；事项标题和金额也可能直接显示在锁屏可见的主屏幕组件上。
