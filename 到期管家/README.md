## 保留的操作与稳定性

- 图标入口统一为「预览 → 确认」：点击网格只改变草稿预览，确认后才应用，取消或返回不应用。最初显示 8 个推荐符号，含自动图标、当前选择及关联场景；菜单切换单一分类，搜索则覆盖全部 200 个本机 SF Symbols。
- 「设置与管理 → 事项图标」可按事项来源、自动／手动方式筛选，并选择是否包含已完成或隐藏的手动事项。集中入口只保存该项图标，不再强制进入完整编辑页；图标方式、颜色和旧图标不可用状态明确显示，提醒事项读取失败可重试。
- 手动编辑页同样使用统一选择器，确认「使用此图标」后仍需保存事项；集中入口则确认「保存图标」直接保存外观。自动匹配会清除该项旧的手选图标及本地覆盖，不影响其他事项。保存继续核对事项版本和图标选择，冲突或失败不自动覆盖。
- 金额显示、三个尺寸预览和上次组件操作移入「组件与显示」，通知、恢复及刷新入口保留在主界面。图标搜索预计算多语言文本，批量覆盖用来源＋ID 索引，主列表一次分组并统一计算时刻；单独改图只请求组件刷新，不维护通知。
- 组件读取提醒最多等待 4 秒，主界面最多 10 秒；超时后采用原有范围内的缓存或显示可重试提示，迟到结果不会覆盖新缓存。多个组件同步时增加共享请求标记，动画与提示读取失败不会把已加载的事项替换成错误页。
- 常规提醒请求 30 分钟后更新，失败或缓存回退请求 5 分钟后重试；真实到期时刻及午夜优先。返回前台、恢复已有脚本或点击「刷新桌面组件」时重新读数据，授权／保存筛选期间的自动刷新会等待设置结束。
- 完成后先请求组件刷新，可选通知维护不再占用下一次完成的队列。保存页最多等待通知维护 1.5 秒；维护延期可在「通知与提醒」查看，原生写入不会因计时器而重复执行。主界面存活时再次点组件主题也会打开准确的备注页。
- 左上角事项主题与系统提醒内容区进入对应提醒的只读备注页，显示完整正文、换行、标题、所属列表及完成状态。备注页先显示加载状态，读取失败、无权限、超时、事项已删除或没有备注时分别提示并可重试；不自动离开页面。
- 备注仅通过准确 ID 在页面打开时实时读取，不写入缓存、URL 或备份，不上传，不执行正文中的链接。「在提醒事项中打开」作为页面内的明确操作，失败不影响备注阅读；非 UUID 账户也可以查看备注。
- 主界面「系统提醒事项 → 查看提醒事项备注」按现有列表筛选及日期范围提供搜索入口；如果宿主未传递组件目标，可从这里自行选择具体事项，不猜测或跳到其他事项。兼容旧版 open-reminder 链接。完成按钮仍只负责完成。

- 仅保留系统图标，移除此前新增的内置 Icons8、在线图库、GitHub／金融品牌图库、登录与搜索模块，以及 829 组 PNG／离线 JSON 素材。不恢复更早已移除的混合品牌 Logo 库。
- 标题、备注在本机分别匹配：明确具体的标题优先；高置信度备注可细化泛化标题，普通备注在泛化标题之后、列表分类之前参与匹配。Wallet Plan 的明确编号模块优先。手选符号始终优先；缓存仅保存图标提示和置信度，不保存 Apple 提醒事项备注正文。
- 桌面小组件的完成按钮把完整点击区域放进实际标签；中、大号行按事项来源、ID 和当前期次标识保持独立身份。完成继续核对真实事项和期次，禁止缓存／只读操作，过期或已不存在的事项明确提示。
- 提醒事项内容区先经 Scripting 接收准确 ID，再呈现备注页；无效或已删除事项明确提示，不回退到其他事项。只有页面内的系统详情按钮依赖 Apple 私有 URL Scheme。
- 升级后运行一次主脚本，会清理本脚本旧图库订阅、相关选图记录和两个本机钥匙串凭据。原先保存的 SF Symbols、事项、周期、日期、通知及完成记录保留；旧外部选图恢复为系统符号。旧 JSON 备份仍可导入，已移除的图库不会被恢复。

验证范围及符号兼容性依据见 [3.5.2 QA](../docs/QA-v3.5.2.md)。本机自动化测试不等同于 iPhone 的原生排版、点击、跳转或通知送达验证。

[在 iPhone 上安装或更新到期管家](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fgithub.com%2FMaroonYS%2Fscripting-due-manager%2Freleases%2Flatest%2Fdownload%2Fdue-manager.scripting%22%5D)

- 交互式桌面组件要求 iOS 17 或更高版本；直接读取／完成 Apple 提醒事项需要支持 Reminder.get 的 Scripting 2.4.9 或更新版本。新增符号的实际可用性与宿主系统有关，最终以设备验证为准。
- 在 iPhone 确认更新原有脚本，不要先删除它。更新后运行一次主脚本，使旧图库设置得到清理，并实时读取提醒事项、重新计算图标和请求刷新小组件。
- 如需系统提醒事项，开启对应开关并在可见主界面授予权限，再选择全部列表或一个／多个具体列表。小组件不能弹出授权框。
- 首次安装时添加 Scripting 桌面组件，长按「编辑小组件」选择「到期管家」；已有组件通常无需重建。
- 后续使用同一固定链接或「检查并更新版本」。远程资源允许每小时检查，实际更新时机由 Scripting 决定。主动安装前保存快照，并拒绝降级和重复安装。

## 事项与图标

手动事项支持信用卡、订阅会员、账单缴费、贷款分期、保险保单、数字服务、证件合同、保养维护、预约日程、纪念日期和其他事项。可填写明确日期、可选时间、金额和备注。

重复支持每 1–99 天、周、月或年，保留月底和闰日锚点。「间隔」和「提前提醒」同处「重复」卡片，左侧名称及右侧单位固定显示。提前天数范围为 0–365：行动日零点开始进入待处理，实际到期日和周期锚点不变；未提前的定时事项按真实时刻处理，全天事项到期日进入待处理、次日才逾期。

主界面「设置与管理 → 事项图标」提供统一的逐项设置入口；编辑手动事项时也可点「图标」。选图页先显示 8 个推荐符号及当前大图预览，点击只改变预览，再点右上角确认；取消或返回不应用。推荐结合自动图标、当前选择、标题／事项类型及关联场景。用「浏览分类」菜单切换财务、影音娱乐、工作效率、数字服务、社交通讯、居家生活、健康运动、出行旅行、学习阅读、创作设计或其他，搜索覆盖全部 200 个符号，支持简体、繁体、英文、SF Symbol 名称及常见场景别名。

在集中入口确认「保存图标」仅保存图标；在编辑页确认「使用此图标」只更新当前表单，仍需点「保存」保存事项。图标列表可按来源及自动／手动方式筛选，默认不显示已完成或隐藏的手动事项，可打开对应开关查看。自动匹配跟随事项内容变化；手动指定固定使用所选符号。选择自动匹配并确认保存会同时清除该项旧的手动图标与本地覆盖，不修改系统提醒本身。

自动匹配完全在设备进行，按标题与备注中的具体词语选择类别符号，不显示品牌原始 Logo，也不表示产品推荐。标题、列表与备注分别处理，不跨字段拼接虚假命中。新增长度上限内的备注识别保留隐私边界：快照仅写入白名单图标与置信度，不保存系统备注正文。

## 桌面组件操作

- 小号显示最紧急的 1 件，当前图标 17 pt／完成热区 40 pt；下一事项预告保留固定槽位。
- 中号按实际高度显示 2–3 件，图标 17 pt／完成热区 38 pt；大号显示 3–5 件，行图标 18 pt／热区 40 pt，摘要图标 26 pt。原容量、行高及金额／备注布局保留。
- 点击左侧图标完成本期；手动周期事项只前进一期，一次性事项进入「已完成或隐藏」。Apple 提醒事项会写入系统完成状态，重复提醒的下一次实例由 iOS 管理。
- 点击文字、日期或预告打开相应详情。手动事项打开到期管家编辑页；系统事项进入对应备注页，再可明确选择打开系统详情；读取失败明确报错。
- 已完成、旧期次、缓存和只读事项不能误完成。快速重复点击按真实事项及期次校验；操作失败或已失效的信息可在「组件与显示 → 上次组件操作」查看。
- 完成按钮只记录本期处理状态，不会自动付款、续订、取消订阅或操作任何金融账户。锁屏附件只显示总数，打开 Scripting，不提供单项完成。

组件文案随系统语言使用简体、繁体或英文，日期按完整地区格式。小号标题最多三行，中／大号最多两行；只显示明确日期，不显示相对天数或实时倒计时。中／大号金额与备注仍保留 116／124 pt 单行右栏，过长时收紧字距、最多缩至 85%，再从中间省略。

## 数据、同步与通知

- 事项保存在本机共享 Storage，不进入远程安装包。兼容 schema v1/v2，旧字段安全填充后按既有规则保存为 schema v3；不认识的状态拒绝覆盖。
- 同名提醒列表显示所属账户。列表读取失败不覆盖旧筛选；只有相同筛选范围、24 小时内的成功快照可作缓存显示，且禁止从缓存完成。
- 旧编辑页有保存／删除冲突保护。重要写入前创建快照，支持本机恢复和 JSON 备份。图库清理不删除用户的历史备份文件；旧备份导入时会忽略已退役图库选择。
- 手动事项的本地通知需另行开启；提前天数本身不发通知。通知采用有上限的滚动排程，后续运行补充；系统提醒事项的通知由 Apple 提醒事项管理。
- 共享 Storage 不是密码保险箱，同一宿主中其他脚本理论上可以访问共享域。不要填写完整卡号、密码等秘密，标题和金额也可能在锁屏可见。

## 原生边界

WidgetKit 不是常驻进程。脚本在下一本地午夜、最近行动／到期时刻、正常提醒同步的 30 分钟后、读取失败的 5 分钟后或用户交互时请求刷新，取最早边界。返回主界面也会重读最新数据。以上是请求时间，实际执行、完成后的画面变化和通知展示由 iOS 决定；Scripting 未运行时无法立即获知其他应用里的更改。设备锁定、权限、专注模式和通知摘要均可能影响结果。

完成使用 Button + AppIntent，不调用 Apple 私有完成动画。备注页直接读取所选提醒，不依赖私有 URL。「在提醒事项中打开」另使用未公开的 `x-apple-reminderkit://REMCDReminder/{UUID}`，并先重新查验原始提醒。该地址不是稳定公开 API，不能承诺每个 iOS／账户类型都能直接定位；失败时保留备注页，不用首页回退冒充成功。若小组件点击只启动宿主而未传入目标，请从主界面备注入口选择事项，并反馈设备现象；本机测试无法验证宿主实际传参。

手动事项的时间保持本地墙钟时间；系统提醒事项的具体时间按绝对时刻换算为当前时区，全天属性优先采用系统提供的标志。

## 源码与发行

入口为 `index.tsx`、`widget.tsx` 与 `app_intents.tsx`；`src/` 内分别维护状态、日期、系统图标、统一选图页、分类网格、事项分组、提醒事项读取／导航和组件界面。当前运行代码不含外部图库、图片缓存、OAuth 或图标网络搜索。

`.scripting` 为 ZIP 容器，入口、`script.json`、`src/`、LICENSE 和 NOTICE 位于压缩包根目录，不多套同名文件夹。发行流程逐文件核对源码，附带 SHA256SUMS 和指定仓库／工作流的签名来源证明。
